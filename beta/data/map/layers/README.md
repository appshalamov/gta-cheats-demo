# Слои общей карты GTA — координаты и лицензии

Координаты — факты (мир GTA V, x/y); тексты в приложении — свои. Каждый файл — данные одного источника под его лицензией.

| Файл | Что | Источник | Лицензия |
|---|---|---|---|
| `gta5_ent.json` | коллекции сюжета GTA V, трюковые прыжки, пасхалки и секреты | Enhanced Native Trainer contributors — github.com/FIying-Scotsman/GTAV-EnhancedNativeTrainer | GPL-2.0 |
| `gta5_dh.json` | пролёты под мостами, полёты «на ребре» | danharper/GTAV — github.com/danharper/GTAV | WTFPL |
| `gtao_rc.json` | экшн-фигурки и глушилки сигнала GTA Online | © 2020 root-cause — github.com/root-cause/v-spactionfigures, v-spjammerhunt | MIT |
