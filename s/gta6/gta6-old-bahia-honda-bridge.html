Broken old rail bridge beside the Keys Causeway

📍 Old Bahia Honda Rail Bridge (Bahia Honda State Park) · Bahia Honda State Park, 36850 Overseas Hwy (MM 37), Big Pine Key, FL 33043

Henry Flagler's 1912 railroad truss bridge, turned into a road in 1938 and abandoned in 1972. Spans were removed, so it now stops in mid-channel. In Trailer 1 (0:35) the same broken bridge runs beside the modern Keys Causeway as a seaplane flies over.
