# Secret Base — Cheats & Codes GTA 6 (демо PWA)

Демо приложения-справочника чит-кодов. Архитектура повторяет Cheats Pro (App Store id6739726720),
карта разделов — `../Референс Cheats Pro/Карта разделов Cheats Pro.md`.

Ставится на экран «Домой» телефона, работает офлайн, без сборки и зависимостей (чистые HTML/CSS/JS).

## Как устроено

```
index.html            каркас: онбординг, 4 вкладки, шторка, пейвол
css/styles.css        стили (тёмная/светлая тема — переменные в :root)
js/config.js          игры, платформы, категории, тарифы пейвола  ← правится чаще всего
js/app.js             логика экранов
js/i18n.js            тексты RU/EN и произношение кнопок для озвучки
js/icons.js           иконки и отрисовка кнопок геймпада
js/map.js             вкладка «Карта» (MapLibre + подложка OpenFreeMap, без ключа)
data/map/             места, пасхалки и слой gtadb для карты (собирается tools/build_map.py)
vendor/maplibre/      MapLibre GL 4.7.1 (BSD-3)
data/gta5.json        36 читов GTA 5 (собирается скриптом)
data/gta6.json        29 читов GTA 6 — ПРОГНОЗ (собирается скриптом)
media/                сюда видео-демонстрации: media/<id>.mp4, путь вписать в поле "media"
sw.js                 офлайн-кэш (данные — сначала из сети, чтобы новые коды приходили без обновления)
tools/                build_gta5.py, build_gta6.py, make_icons.py, deploy.sh
```

Экраны: онбординг (игра → платформа) → пейвол (демо, оплата не списывается) → Главная (Мир / Игрок / Оружие /
Транспорт, листаются свайпом) · Поиск · Избранное · Настройки → шторка чита (видео, описание, код, «Озвучить код»
с подсветкой кнопок, все платформы, поделиться).

## Данные

- GTA 5: комбинации — GTA Wiki «Cheats in GTA V», сверены с IGN/Kotaku/Red Bull. Номера телефонов не вписаны руками,
  а считаются из слова (1-999 + слово на клавиатуре телефона); все 35 номеров совпали с вики, в вики ошибка
  у Trashmaster (пропущена цифра) — у нас верно: 1-999-872-7433. Xbox выводится из PlayStation заменой кнопок.
- GTA 6: выходит 19.11.2026 (PS5, Xbox Series X|S; ПК — слух о 2027). На 14.10.2026 подтверждённых кодов нет.
  В приложении — коды GTA 5 с пометкой «Прогноз» и вероятностью. После релиза: в `tools/build_gta6.py`
  заменить на настоящие коды, `status` → `confirmed`, пересобрать и выложить — данные обновятся у всех без переустановки.

Пересобрать данные: `python3 tools/build_gta5.py && python3 tools/build_gta6.py`.

## Запуск на компьютере

```
cd cheats-pwa && python3 -m http.server 8931
```
Открыть http://localhost:8931 (на широком экране приложение показывается в рамке телефона — удобно для записи).
«Сбросить демо» в Настройках — снова пройти онбординг и пейвол (для записи рекламы).

## Публикация

`tools/deploy.sh` — выкладывает на GitHub Pages (репозиторий appshalamov/gta-cheats-demo).
После правок в оболочке (css/js) поднять `VERSION` в `sw.js`, иначе установленное приложение покажет старую версию.

## Карта

Вкладка «Карта» — реальные места GTA 6 (Майами) и GTA 5 (Лос-Анджелес). Данные — из проекта
«../Карта локаций GTA — реальный мир»: `python3 tools/build_map.py` подхватывает проверенные `locations_*.json`
(с русскими текстами и фото), а пока их нет — черновые `_сырьё/*` (тексты EN). Подложка OpenFreeMap
(OpenStreetMap, без ключа; CARTO с 2026 требует ключ). Слой «Все точки» — gtadb.org and contributors, CC BY 4.0.

Нижняя панель: Карта · Главная · Поиск · Избранное; настройки — шестерёнка справа сверху.
На iPhone в режиме «на экране Домой» каркас растягивается на реальную высоту экрана (fitViewport в app.js);
диагностика высоты — в «О приложении» (строка vp).
